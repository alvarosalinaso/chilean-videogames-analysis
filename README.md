## What is this?

EN: There's no structured, reproducible data about the Chilean indie game market. This repo scrapes Steam and Itch.io, cleans the dataset, and analyzes pricing, genres, estimated revenue, and platform differences, every number in this README is generated by a script from the data in the repo.

ES: No hay datos estructurados y reproducibles sobre el mercado indie de videojuegos chilenos. Este repo hace scraping de Steam e Itch.io, limpia el dataset y analiza precios, géneros, revenue estimado y diferencias por plataforma, cada número de este README lo genera un script a partir de los datos del repo.

## Qué mide y qué no

**Qué mide:**

- Juegos chilenos presentes en Steam (API `appdetails`) y en el tag `chile` de Itch.io (scraping HTML), con sus precios listados, géneros y reseñas (recommendations) de Steam.
- Revenue **estimado** con el método Boxleiter: `revenue = recommendations × factor × price` (factor base 40; el README reporta 20x/40x/60x).
- Concentración de mercado por género con el HHI calculado sobre `primary_genre` (incluye `Unknown` como categoría).

**Qué no mide:**

- Ventas ni ingresos reales: no hay datos de revenue real de Steam ni de Itch.io; toda cifra de revenue es una estimación proporcional al factor Boxleiter.
- Wishlists, tráfico, reseñas negativas/positivas (solo el conteo total de recommendations), calidad ni presupuesto.
- Itch.io no expone recommendations: su valor es `0` estructural, no "cero ventas".
- El universo completo del indie chileno: solo juegos todavía publicados en estas dos tiendas (sesgo de supervivencia) y en el tag curado de itch.io.
- Los nombres de género **no se traducen** entre plataformas: Steam entrega etiquetas localizadas (ej. `Acción`) y itch.io etiquetas en inglés (ej. `Action`), por lo que una misma categoría puede contar dos veces.

## Fuentes y licencias

- **Steam API** (`appdetails`): datos de tienda de Valve, uso analítico; no se redistribuye contenido de la API, solo los campos capturados por el scraper de este repo.
- **Itch.io** (tag `chile`): scraping HTML del listado general y del listado pagado (`/games/store/tag-chile`, único lugar donde aparecen precios).
- **Método Boxleiter**: heurística de la industria ("cada reseña ≈ 30–60 ventas"); este repo usa 40 como factor base y publica la sensibilidad 20x–60x.
- **Código de este repo**: MIT (ver [LICENSE](LICENSE)).
- Los datasets crudos (`data/raw/`) son snapshots de esas fuentes con derechos de sus titulares; se publican con fines de análisis.

## How to run

```bash
git clone https://github.com/alvarosalinaso/chilean-videogames-analysis
cd chilean-videogames-analysis
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
pip install -r requirements-dev.txt
pip install -e .

python -m chilean_videogames.collect                 # Steam (requiere red)
python -m chilean_videogames.collect_itch            # Itch.io (requiere red)
python -m chilean_videogames.clean
python -m chilean_videogames.analyze_all
python -m chilean_videogames.export_visualizations

python scripts/readme_numbers.py --write             # regenera la tabla del README
python scripts/readme_numbers.py --check             # verifica que el README coincide
pytest                                               # tests (incluye la verificación del README)
```

Los módulos viven en `src/chilean_videogames/` y se ejecutan con `python -m` (paquete instalado en editable); `python src/collect.py` falla por los imports relativos del paquete. En Windows, `update_data.bat` ejecuta el pipeline completo.

## Limitations

- Revenue estimates depend entirely on the Boxleiter factor; see the 20x–60x sensitivity in the generated table (rankings do not change, only absolute amounts).
- The vast majority of titles have no recommendation data (see generated table); on Itch.io the field does not exist (structural zero).
- Genre labels mix Spanish (Steam) and English (Itch.io) and are not translated; the HHI and genre counts treat them as separate categories.
- Survival bias: only games still listed on the platforms are included.
- Year is unknown for a large share of Itch.io titles (see generated table).
